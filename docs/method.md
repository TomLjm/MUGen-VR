# MUGen-VR Method

MUGen-VR is not a wrapper around several foundation models. The backbones provide modality-specific competence; the project contribution is the system that turns them into a unified, trainable, retrieval-augmented generation pipeline.

## What Is Ours

- **HierarchicalConditionFusion** projects text, image, audio, and reference features into a shared condition space and uses hierarchical gating to expose how each modality contributes.
- **ModalityDropout + ConfidenceWeighting** trains the fusion path to survive missing or weak modalities instead of assuming every input is present.
- **Reference-Conditioned Retrieve-then-Generate** retrieves similar video references and injects their representation into the generation condition.
- **Unified Evaluation Report** records retrieval quality, alignment quality, temporal statistics, generation metadata, and unavailable third-party metrics as explicit skipped fields.

## Training Strategy

The first trainable target is the small MUGen-owned condition stack: fusion, reference adapter, and optional reranker. Foundation models are kept frozen. AnyFlow LoRA is a second-stage optional adaptation, not a requirement for the first release.

## Current Demonstration Boundary

The current showcase has two layers:

- **MUGen-owned condition layer**: text, image, audio, and retrieved references are embedded, fused by `HierarchicalConditionFusion`, exposed as gating weights, and converted into a reference-conditioned generation plan.
- **AnyFlow backend layer**: AnyFlow receives the image condition and the MUGen-enhanced prompt to generate video frames.

This is intentionally honest: the audio signal participates in fusion, retrieval, and prompt planning today, but it is not yet a direct AnyFlow latent condition. The next research step is to train `ReferenceAdapter` / lightweight generator adapters so the fused condition can enter the video generator more deeply than prompt augmentation.

## Release-Quality Evidence

A credible release should include at least three artifacts per example:

- An MP4 generated by the backend, not only a GIF preview.
- A multimodal report showing input modalities, retrieval results, and gating weights.
- An ablation comparison between base AnyFlow prompt, MUGen-enhanced prompt, and missing-modality variants.
